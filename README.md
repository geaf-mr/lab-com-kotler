# Laboratorio colaborativo de Comercialización

Simulador para los capítulos 3 y 4 de Kotler y Armstrong.

Incluye 29 piezas didácticas distribuidas en cinco módulos:

- seis diagnósticos multidimensionales del entorno;
- cuatro desafíos de investigación de mercados;
- cuatro simulaciones de directorio;
- tres ejercicios cuantitativos;
- doce tarjetas de maestría conceptual.

## Estado actual

La versión publicada permite probar salas colaborativas entre pestañas del mismo navegador mediante almacenamiento local. La conexión entre dispositivos diferentes se incorporará mediante Firebase en una etapa posterior.

## Desarrollo local

```powershell
python -m http.server 4178
```

Luego abrir `http://127.0.0.1:4178/`.
